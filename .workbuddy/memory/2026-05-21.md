# 2026-05-21 工作日志

## 搭建 PyTorch + DeepSpeed + Megatron-LM 集成训练框架

### 新增模块: LLMT-training/
完整训练框架模块，集成三大框架：

- **config/**: 统一配置系统（TrainingConfig Pydantic 模型 + ConfigMerger 生成 DeepSpeed JSON / Megatron CLI args + ConfigValidator 交叉校验）+ 默认配置文件（deepspeed_zero1/2/3/3_offload.json, megatron_gpt/bert_345m.yml）
- **core/**: 核心抽象（BaseTrainer, BaseDataset, BaseModelProvider, TrainingCallback, TrainingState, CallbackList）
- **trainers/**: PyTorchTrainer (DDP), DeepSpeedTrainer (ZeRO 1/2/3 + offload), MegatronTrainer (TP/PP/3D), TrainerFactory
- **models/**: GPTModelProvider + GPTModel, BERTModelProvider + BertModel, ModelRegistry
- **data/**: PretrainDataset (npy/bin), FinetuneDataset (jsonl), MegatronDataset, data_utils
- **launcher/**: TorchrunLauncher, DeepSpeedLauncher, MegatronLauncher, LauncherFactory
- **reporting/**: InfluxDBMetricsWriter, PostgresStatusUpdater, MinIOCheckpointer, ReportingCallbackBridge
- **cli/**: Click CLI (llmt-train train/eval)
- **examples/**: gpt_pretrain.py, bert_finetune.py, configs/ (DeepSpeed/PyTorch JSON configs)
- **tests/**: test_config.py, test_core.py, test_data.py
- **Dockerfile.training**: GPU 集群部署镜像

### 架构设计
- 用户 POST /api/v1/training/tasks → TrainingService → PostgreSQL INSERT → Celery dispatch
- Celery Worker → 加载配置 → 校验 → 创建 Trainer + Launcher → 执行训练
- ReportingCallbackBridge → InfluxDB (指标) + PostgreSQL (状态) + MinIO (检查点)
